# בריף יומי (daily-brief)

**בריף בית-ספר יומי אוטומטי ממשו״ב — מותקן אצלך, עם הבוט שלך, בחינם ובקוד פתוח.**

כל בוקר יום לימודים, הקוד אוסף את מערכת השעות, שיעורי הבית והאירועים של הילדים
ממשו״ב, ומפיק הודעה אחת מסודרת בסגנון וואטסאפ. הבוט האישי שלך (Instinct, Claude,
Tab, Pally או אחר) שולח אותה אליך. אין שירות מרכזי, אין רישום, אין תשלום —
כל משתמש משכפל את הריפו ומריץ מופע משלו עם החשבון והנתונים שלו.

## כיסוי: מה ממומש, מה לא, ולמה

| תכונה | סטטוס | הערה |
|-------|--------|------|
| מערכת שעות + שיעורי בית (משו״ב) | ⚠️ ניסיוני | מיפוי מכוסה בפיקסצ׳רים, ממתין לכיול חי |
| הודעות ממורים (דואר משו״ב) | ⚠️ ניסיוני | get_conversations עם skip/take; קבצים מצורפים **מסומנים 📎 בלבד, לא מורדים** |
| ציונים ואירועי משמעת | 🚫 לא נאספים בכוונה | מידע רגיש לעיני הורה בלבד, לא לבריף משפחתי; הוספה = החלטת פרטיות מפורשת של כל משתמש |
| יומן (הצלבת מקורות) | ✅ ממומש | קובץ ICS מקומי או URL ציבורי, ספרייה סטנדרטית בלבד; סתירות תאריכים מדווחות עם שני המקורות והתאריכים |
| שער שלמות | ✅ ממומש | מקור שנכשל/חלקי מופיע כשורת ⚠️ בבריף; מבנה לא מוכר עוצר עם הודעה ברורה |
| סמן ריצה אחרונה (אידמפוטנטות) | ✅ ממומש | out/state.json מקומי; הודעות חדשות מסומנות 🆕 פעם אחת, בלי כפילות בריצה חוזרת |
| תאריכים | ✅ ממומש | יום השבוע מחושב מלוח השנה האמיתי (מהקוד, לא מהבוט) |
| מתאמי מקור נוספים (Webtop וכו׳) | 🔜 עתידי | חוזה אחד: `collect() -> DayBrief` |

## למה קוד + הוראות, ולא "עוד בוט"

- **דטרמיניסטי ומאומת.** איסוף, אימות, דה-דופליקציה ועיצוב קורים בקוד — לא
  מושארים לשיקול דעת של בוט בכל בוקר מחדש.
- **הבוט שלך נשאר הבוט שלך.** ההוראות (SKILL.md / AGENTS.md / מתכון טקסט)
  אומרות לבוט *מתי* ו*איך* להריץ; הקוד מחליט *מה* נשלח.
- **חינם לגמרי.** Python, ספריית pymashov הפתוחה, ותזמון מקומי (cron). בלי
  חשבונות חדשים ובלי מנויים.

## התחלה מהירה (דמו, בלי התחברות)

```bash
git clone https://github.com/ofershap/daily-brief.git
cd daily-brief
pip install -e .
daily-brief --demo
```

## הגדרה אמיתית מול משו״ב

```bash
pip install -e ".[mashov]"
cp .env.example .env   # ומלאו: ת.ז, סיסמה, סמל בית ספר, שם=מזהה לכל ילד
daily-brief --collector mashov
```

מסלול מודרך לסוכן קוד (clone ← תלויות ← קונפיגורציה ← דמו ← מבחן חיה ← תזמון):
**[AGENTS.md](AGENTS.md)**. תזמון בוקר מקומי לדוגמה:

```cron
0 7 * * 0-4  cd /path/to/daily-brief && .venv/bin/daily-brief --collector mashov --out out/brief.txt
```

## ארכיטקטורה: אגנוסטי למקור, מתאם ראשון משו״ב

```
מקור (מתאם)          ליבה דטרמיניסטית          מסירה
─────────────        ──────────────────        ─────────────
משו״ב (pymashov) ──> DayBrief ← formatter ──> stdout / קובץ
Webtop (עתידי)       (models.py)              הבוט שלך שולח
יומן (עתידי)                                  את הטקסט כמו שהוא
```

מתאם חדש מממש חוזה אחד (`collect() -> DayBrief`). המתאם הראשון משתמש
ב-[pymashov](https://github.com/t0mer/pymashov) (Apache-2.0) כתלות, עם
סשן אחד משותף לכל הילדים כדי להימנע מהצפת התחברויות.

## פרטיות ושימוש אחראי

- **אין שרת מרכזי של הפרויקט ואין איסוף נתונים מרכזי.** הקוד רץ אצלך.
- זה **לא** מסיר אמון בצד שלישי: אם תחבר בוט ענן, מודל שפה או ספק שליחת
  הודעות, תוכן הבריף יעובד גם אצלם. משתני סביבה מקומיים לא מבטיחים שהנתונים
  נשארים מקומיים.
- לכן כל מתאם/מסירה מתועד: מה זורם לאן ובאילו הרשאות, וברירת המחדל היא צמצום
  (השמטת פרטים מזהים לפני שהטקסט יוצא למודל חיצוני). זו דרישת תיעוד של
  הפרויקט, לא פטור משפטי.
- pymashov היא ספרייה **לא-רשמית** מול API לא מתועד שיכול להשתנות. שימוש
  אישי בלבד, עם החשבון שלך או של ילדך, ובקצב בקשות נמוך. הנתונים הם מידע
  אישי על קטינים — שמור אותם פרטיים.
- סיסמאות: קובץ `.env` מקומי בלבד. לעולם לא בצ'אט, לא בלוגים, לא בריפו.
