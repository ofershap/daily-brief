# בריף בית-ספר יומי להורים (mashov-parent-brief)

> **גם אתם פותחים את משו״ב כל בוקר כדי לרדוף אחרי מערכת, שיעורי בית והודעות של כמה ילדים — ועדיין מגלים על הטיול רק ביום לפני?**

**בריף בית-ספר יומי אוטומטי ממשו״ב — מותקן אצלך, עם הבוט שלך, בחינם ובקוד פתוח.**

כל בוקר יום לימודים, הקוד אוסף את מערכת השעות, שיעורי הבית והאירועים של הילדים
ממשו״ב, ומפיק הודעה אחת מסודרת בסגנון וואטסאפ. הבוט האישי שלך (Instinct, Claude,
Tab, Pally או אחר) שולח אותה אליך. אין שירות מרכזי, אין רישום, אין תשלום —
כל משתמש משכפל את הריפו ומריץ מופע משלו עם החשבון והנתונים שלו.

>

> · מזכירות: טופס הצטרפות לחוג מדעים 📎 (30.10.2026)

## כיסוי: מה ממומש, מה לא, ולמה

| תכונה | סטטוס | הערה |
|-------|--------|------|
| מערכת שעות + שיעורי בית (משו״ב) | ⚠️ ניסיוני | צורת התשובה אומתה מול משיכה חיה (ערכים מומצאים); מספור ימים דורש כיול, מועד הגשה אינו מתועד — מוצג תאריך מתן בלבד |
| הודעות ממורים (דואר משו״ב) | ⚠️ ניסיוני, צורה לא אומתה | get_conversations עם skip/take; המיפוי על צורה משוערת וייכשל סגור אם המבנה האמיתי שונה; קבצים מצורפים **מסומנים 📎 בלבד, לא מורדים** |
| ציונים ואירועי משמעת | 🚫 לא נאספים בכוונה | מידע רגיש לעיני הורה בלבד, לא לבריף משפחתי; הוספה = החלטת פרטיות מפורשת של כל משתמש |
| יומן (הצלבת מקורות) | ✅ ממומש, מוגבל ביודעין | קובץ ICS מקומי או URL ציבורי, ספרייה סטנדרטית בלבד; סתירות תאריכים מדווחות עם שני המקורות והתאריכים. חזרות נתמכות ב-DAILY/WEEKLY פשוט בלבד (+EXDATE); שעות UTC מומרות ל-Asia/Jerusalem; כל תכונה לא נתמכת (MONTHLY, RDATE וכו׳) = שורת ⚠️ "יומן חלקי" ואזהרה מפורשת, לא השמטה שקטה |
| שער שלמות | ✅ ממומש | מקור שנכשל/חלקי מופיע כשורת ⚠️ בבריף; מבנה לא מוכר עוצר עם הודעה ברורה |
| סמן ריצה אחרונה (אידמפוטנטות) | ✅ ממומש | out/state.json מקומי; הודעות חדשות מסומנות 🆕 פעם אחת, בלי כפילות בריצה חוזרת |
| תאריכים | ✅ ממומש | יום השבוע מחושב מלוח השנה האמיתי (מהקוד, לא מהבוט) |
| מתאמי מקור נוספים (Webtop וכו׳) | 🔜 עתידי | חוזה אחד: `collect() -> DayBrief` |

## למה קוד + הוראות, ולא "עוד בוט"

- **דטרמיניסטי ומאומת.** איסוף, אימות, דה-דופליקציה ועיצוב קורים בקוד — לא
  מושארים לשיקול דעת של בוט בכל בוקר מחדש.
- **הבוט שלך נשאר הבוט שלך.** ההוראות (SKILL.md / AGENTS.md / מתכון טקסט)
  אומרות לבוט *מתי* ו*איך* להריץ; הקוד מחליט *מה* נשלח.
- **חינם לגמרי.** Python, ספריית pymashov הפתוחה, ותזמון מקומי (cron). בלי
  חשבונות חדשים ובלי מנויים.

## התחלה מהירה (דמו, בלי התחברות)

```bash
git clone https://github.com/ofershap/mashov-parent-brief.git
cd mashov-parent-brief
pip install -e .
daily-brief --demo
```

## הגדרה אמיתית מול משו״ב

```bash
pip install -e ".[mashov]"
cp .env.example .env   # ומלאו: ת.ז, סיסמה, סמל בית ספר, שם=מזהה לכל ילד
daily-brief --collector mashov

בריצה ראשונה המתאם יעצור ויבקש כיול של מספור הימים (MASHOV_DAY1_IS):
הריצו, השוו מול המערכת האמיתית באתר משו״ב, ומלאו איזה יום מייצג day=1
(AGENTS.md, צעד 5). לא מניחים את המיפוי בשבילכם.
```

מסלול מודרך לסוכן קוד (clone ← תלויות ← קונפיגורציה ← דמו ← מבחן חיה ← תזמון):
**[AGENTS.md](AGENTS.md)**. תזמון בוקר מקומי לדוגמה:

```cron
0 7 * * 0-4  cd /path/to/daily-brief && .venv/bin/daily-brief --collector mashov --out out/brief.txt
```

## ארכיטקטורה: אגנוסטי למקור, מתאם ראשון משו״ב

```
מקור (מתאם)          ליבה דטרמיניסטית          מסירה
─────────────        ──────────────────        ─────────────
משו״ב (pymashov) ──> DayBrief ← formatter ──> stdout / קובץ
Webtop (עתידי)       (models.py)              הבוט שלך שולח
יומן (עתידי)                                  את הטקסט כמו שהוא
```

מתאם חדש מממש חוזה אחד (`collect() -> DayBrief`). המתאם הראשון משתמש
ב-[pymashov](https://github.com/t0mer/pymashov) (Apache-2.0) כתלות, עם
סשן אחד משותף לכל הילדים כדי להימנע מהצפת התחברויות.

## פרטיות ושימוש אחראי

- **אין שרת מרכזי של הפרויקט ואין איסוף נתונים מרכזי.** הקוד רץ אצלך.
- זה **לא** מסיר אמון בצד שלישי: אם תחבר בוט ענן, מודל שפה או ספק שליחת
  הודעות, תוכן הבריף יעובד גם אצלם. משתני סביבה מקומיים לא מבטיחים שהנתונים
  נשארים מקומיים.
- לכן כל מתאם/מסירה מתועד: מה זורם לאן ובאילו הרשאות, וברירת המחדל היא צמצום
  (השמטת פרטים מזהים לפני שהטקסט יוצא למודל חיצוני). זו דרישת תיעוד של
  הפרויקט, לא פטור משפטי.
- pymashov היא ספרייה **לא-רשמית** מול API לא מתועד שיכול להשתנות. שימוש
  אישי בלבד, עם החשבון שלך או של ילדך, ובקצב בקשות נמוך. הנתונים הם מידע
  אישי על קטינים — שמור אותם פרטיים.
- סיסמאות: קובץ `.env` מקומי בלבד. לעולם לא בצ'אט, לא בלוגים, לא בריפו.

## שאות ותשובות

**למי זה מיועד?**
להורים בישראל שבית הספר של ילדיהם עובד עם משו״ב, ושרוצים הודעת בוקר אחת מסודרת במקום לצלול כל יום לכמה מסכים.

**איפה נשמרים הנתונים שלי?**
אצלך בלבד. כל משתמש משכפל את הריפו ומריץ מופע משלו על המחשב שלו, עם החשבון שלו. אין שירות מרכזי, אין רישום, ושום נתון לא נשלח לשום צד שלישי. קובץ ה-.env עם הסיסמה נשאר מקומי ומכוסה ב-.gitignore.

**אילו בוטים נתמכים?**
כל בוט שיכול להריץ פקודה מתוזמנת ולקרוא קובץ טקסט: דרך קובץ SKILL.md (תקן Agent Skills הפתוח) או דרך מתכון טקסט חופשי לבוטים מבוססי-שיחה. תאימות לבוט ספציפי טרם אומתה בבדיקה אמיתית — זה הצעד הבא במפת הדרכים.

**זה כבר עובד מול משו״ב אמיתי?**
מצב הדמו עובד מקצה לקצה ומכוסה בבדיקות. המתאם החי ניסיוני: צורות המערכת ושיעורי-הבית אומתו מול משיכה חיה (ערכים מומצאים), צורת ההודעות טרם אומתה, ומספור הימים דורש כיול חד-פעמי מול החשבון שלך. פרטים מדויקים בטבלת הסטטוס למעלה.

**מה עם קבצים מצורפים בהודעות ממורים?**
מסומנים 📎 בלבד — הבריף מודיע שקיים קובץ מצורף, אבל לא מוריד אותו.

**למה אין ציונים ואירועי משמעת בבריף?**
בכוונה. זה מידע רגיש לעיני הורה בלבד, לא לבריף משפחתי שעלול להיקרא על ידי הילדים. הוספה שלהם היא החלטת פרטיות מפורשת של כל משתמש בנפרד.

**כמה זה עולה?**
הקוד עצמו — כלום. קוד פתוח (MIT), רץ על Python וספריות חינמיות, עם תזמון מקומי (cron). בלי חשבונות חדשים לצורך הבריף. שים לב: הבוט האישי שאתה בוחר להפעיל הוא שירות צד-שלישי שעשוי לגבות מנוי משלו — התנאים שלו נבדקים אצלו, לא כאן.

**אילו בתי ספר נתמכים?**
כל בית ספר שעובד עם משו״ב. בתי ספר על מערכות אחרות (Webtop וכו׳) ידרשו מתאם נוסף; החוזה פתוח (`collect() -> DayBrief`).
